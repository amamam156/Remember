# 🇨🇴 Colombia

[![npm version](https://badgen.net/npm/v/@svg-maps/colombia)](https://www.npmjs.com/package/@svg-maps/colombia)
[![License: CC BY 4.0](https://img.shields.io/badge/License-CC%20BY%204.0-blue.svg)](https://creativecommons.org/licenses/by/4.0/)

Contains all the departments of Colombia:
* Amazonas
* Antioquia
* Arauca
* Atlántico
* Bogotá
* Bolívar
* Boyacá
* Caldas
* Caquetá
* Casanare
* Cauca
* Cesar
* Chocó
* Córdoba
* Cundinamarca
* Guainía
* Guaviar
* Huila
* La Guajira
* Magdalena
* Meta
* Nariño
* North Santander
* Putumayo
* Quindío
* Risaralda
* San Andrés y Providencia
* Santander
* Sucre
* Tolima
* Valle del Cauca
* Vichada
* Vaupés

## Installation

### npm

`npm install --save @svg-maps/colombia`
